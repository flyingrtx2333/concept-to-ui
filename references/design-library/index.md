12 个实看案例，含本地截图、来源、日期、具体观察与迁移边界。2026-10-12 更新。多数通过 recent.design 的 Web 分类或 Websites 目录发现；Antigravity 与 Linear 是补充参考。截图保留原站/画廊预览的文字，只供设计研究；不代表这些文案可用于产品。

## How to use

Choose cases by the actual task and visual intent. Read a relevant note and open its images before citing it. Use a few complementary sources, usually one composition reference and one craft/detail reference; add motion research only when needed. Do not load all images or blend entire sites into one design.

For each selected case, write a concrete transformation in the concept brief: observed relationship → product-specific adaptation → feasibility. Example: thin radial time marks → a precise timeline/progress display → native Path/Canvas with truthful data. Identify what stays behind. A signature can come from type or real data graphics, not mandatory 3D/particles.

Captured marketing typography, English, logos and claims are reference content, not approved copy or reusable product assets. Recreate original product-specific geometry/imagery with real text and controls; never paste a screenshot into the product. Do not attach whole reference pages as generation targets. If an image reference is useful, label it as style context and preserve product scope separately.

Gallery previews establish appearance only. Descriptions and technology labels are metadata, not proof of working animation. Read the case's evidence level before making motion claims. Verify relevant current originals when implementation depends on them.

## Selection routes

- Compact native/data workspace: Harry Atkins for baseline/grid craft, Linear for tonal hierarchy, CO’WATCH! or Paper Mono for functional geometry and numerals. Reduce display-scale typography to real window sizes.
- Atmospheric H5/product introduction: Augen for light/asymmetry, Antigravity for sparse fields, Octolane for localized light. Choose one coherent expressive language rather than stack all effects.
- Portfolio/editorial/gallery: Gregor Collienne for image rhythm, Harry Atkins for disciplined project organization, cassette portfolio for coherent spatial framing.
- Brand-led landing/scene transition: Podium for a meaningful domain-shaped visual anchor, Displace for separating stable controls from media, Antimetal for capability-based imagery.
- Mini-program/mobile task: borrow the selected case's proportion/contrast/type relationships; protect touch targets, safe areas and short flows. Do not carry pointer dependence, heavy 3D or hero-level whitespace into a compact form.

These are retrieval suggestions, not fixed templates. Include unfamiliar original directions when the product calls for them. A gallery appearance is not objective proof of high-end quality or usability.

## Maintenance and limits

New cases should add a distinct reusable decision, not duplicate a palette. Keep source/date, representative screenshots, observed detail, adaptation, avoid choices and motion limitations together. Retire incomplete or unhelpful examples instead of growing an exhaustive catalog. The manifest records each file's dimensions and digest; it does not score aesthetic quality.

The current library contains desktop observations. Mobile behavior and performance were not verified. Shopify Winter ’26 was excluded because the observed captures stayed in its introduction state; failed or partial captures are not promoted into full case references. No source code, remote video files, credentials, product data or internal project paths are bundled.
