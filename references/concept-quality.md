# Curate before the first user-facing delivery

Read before generation and the visual-selection checkpoint. Deliver a strong first set so the user chooses a direction rather than performs the quality review. This is a workflow requirement, not a guarantee that one model call wins subjective approval.

## Resolve composition before rendering

Separate audited product roles from inherited layout. Preserve required functions and authorized information architecture, but do not inherit rejected card structures, positions, oversized headings or redundant copy. Do not hide essential controls for aesthetics. Secondary states need not all be expanded at once merely because their functions must remain accessible.

Write a short spatial plan per direction: first/second/third reading priorities, region proportions at the target viewport, useful negative space, and one visual grammar connecting type, graphics, controls and surfaces. Name one reference-based craft decision and its product-specific transformation. Compare the plans: if they reduce to the same metrics/chart/table arrangement with different palettes, revise them before generating. Merely shuffling sections is insufficient. Remove effects mentally; the composition should still have identity.

## Art direction instead of a constraint wall

Order the prompt: composition thesis and reading path; platform/viewport; type/material relationships; essential content and copy whitelist; a few consequential exclusions. State each invariant once. Avoid repeated luxury adjectives, brand-name lists, conflicting micro-instructions or a blanket ban on expressive techniques. Long prompts may be necessary for content, but verbosity itself adds no craft.

Inspect the current screenshot, then decide whether attaching it helps. If it anchors generation to a rejected template, pass its audited functions as text instead or use an appropriate regional crop. Approved layouts remain explicit constraints. Library images are limited style context: specify the relationship to adapt and exclude copied branding, wording and marketing proportions. Keep product and style references distinct.

Use a small coherent fixture and necessary labels rather than repeating incidental decimals, currencies and expanded secondary states. Preserve truthful visible encodings and essential information; simplification cannot fabricate results. Real product data remains intact during implementation.

## Review drafts before offering a choice

Generate one initial candidate per planned direction and save its prompt/path. Image-tool output may be visible automatically: do not promise hidden generation. Treat it as a draft; do not ask for selection before review.

Inspect actual target-size appearance, full-resolution critical regions, and the set together. Compare craft with the selected reference images rather than copied pixels. Diagnose through visible evidence and locations, not self-awarded aesthetic scores.

Block presentation for:

- Interchangeable template composition whose identity depends on its name, palette, generic glow or particle overlay.
- Several equally loud elements, coarse type, inconsistent numerals, weak spacing rhythm or incidental voids.
- Charts, icons or imagery that lack the composition's level of craft and coherent visual grammar.
- Missing actions, unreadable essential text, redundant English/subtitles, scope violations or infeasible interaction.
- Clearly misleading chart geometry, inconsistent visible labels or obvious percentage/proportion errors in prominent graphics.

“Fix it in implementation” does not make a blocked concept ready. Minor residuals can include a tiny glyph artifact, subtle edge approximation or pixel-level difference only when they do not affect direction, meaning or usability. Do not relabel blocking defects as residuals to finish.

## Repair the decision responsible for failure

| Failure | Required change |
| --- | --- |
| Generic dashboard plus effect | Rewrite composition/reading path and domain-specific grammar; do not add another effect. |
| Everything loud | Remove competing emphasis and revise type/space relationships, not uniform font reduction. |
| Refined hero above rough modules | Carry the same grid, type and material rules into supporting regions; remove redundant wrappers. |
| Wrong prominent data proportions | Correct explicitly or use a simpler reliably encoded graphic; preserve truthful values. |
| Reference identity disappears | Restore the lost scale/contrast/spacing relationship within platform limits, rather than copy the source page. |

Use the built-in image tool for a targeted edit when structure is sound and defects are local; inspect the target first. Regenerate from a revised brief when composition fails. Do not retry unchanged prompts, accumulate adjectives or redraw randomly.

Keep refinement bounded: normally one initial candidate and up to two justified repair calls per direction, fewer if it passes immediately. Honor user budgets; do not automatically spend the allowance or rerun passing directions. Replace a failed thesis within the remaining allowance. If the acceptable set still cannot be produced, report the concrete limitation rather than pass failed drafts off as finished or ask the user to conduct the quality review. Do not run indefinitely.

## Deliver the curated set

Default A/B/C means three materially different candidates that passed review, unless the user requests another count. Tradeoffs describe real choices, not missing polish. Do not pad the set with weak options, choose silently, integrate the product, or start motion before visual selection.

Save `concept-review.md` with draft IDs, reference cases, blocking observations, repairs, final paths, minor residuals and ready/blocked status. Put discarded candidates in a manifest `drafts` collection; `concepts` contains only final selectable candidates. Record actual decisions without pretending aesthetic quality is numerically guaranteed.

Skill validation and checklist completion do not prove output improved. The eventual generated images provide that evidence; report this distinction honestly.
